Build a complete **Finance Management Web Application** for my college project.

## MAIN REQUIREMENT

The project must be **primarily developed in JAVA**.

Use:

* **Java**
* **Spring Boot**
* **Spring MVC**
* **Spring Data JPA**
* **MySQL**
* **Thymeleaf**
* Maven

HTML and CSS can be used for the frontend UI, but keep them limited to presentation and layout. Use only minimal JavaScript where absolutely necessary.

**Do NOT use React, Node.js, Express, Python, PHP, Supabase, Firebase, or any other backend technology.**

The main application logic, authentication, calculations, CRUD operations, validations, database operations, reports, budgets, transactions, and business logic must be handled using **Java + Spring Boot**.

The project should be easy to run directly on **Replit**.
